# gallery.chrjl.dev

[Astro](https://astro.build) with [React](https://react.dev) and [Tailwind](https://tailwindcss.com) integrations, and [Tailwind Typography](https://tailwindcss-typography.vercel.app/) styles.

## Development

| Command      | Action                                      |
| :----------- | :------------------------------------------ |
| `pnpm dev`   | Starts local dev server at `localhost:4321` |
| `pnpm build` | Build your production site to `./dist/`     |
